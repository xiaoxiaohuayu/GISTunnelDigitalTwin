# 隧道配置与设备台账，第一批

已确认：浏览器本地保存，完整配置导入导出；支持单洞、双洞，以及每个洞筒内单向或双向车道。设备类型的亮度、开度等精细控制后续逐类增加。

数据关系为隧道项目 → 物理洞筒 → 车道。设备使用稳定 ID，关联洞筒和绝对桩号，位置还包括横向偏移、高度、朝向。洞筒各有自己的起止桩号，起止可以递增或递减。设施可有结束桩号。

本批通过配置管理入口编辑项目、洞筒和台账。批量录入使用 Excel 可打开的 CSV 模板，导入先预览并逐行校验，保存后应用；完整 JSON 配置有版本号。存储使用现有 IndexedDB 设置库。原演示场景保留，在尚未保存项目配置时继续可用。

配置场景按实际洞筒和车道生成三维结构，车道方向驱动车流和标线，设备台账驱动实体、列表、拾取和独立控制。已有演示资产的洞口是固定双洞模型，不能通过拉伸冒充任意断面，因此配置场景使用参数化洞门和衬砌。地理位置采用入口中心经纬度、高程、线路方位及纵坡，当前支持直线线路。

验收：单洞双向与双洞不同车道数均可保存和重载；桩号正确换算且越界报错；CSV 预览不改变场景；重复编号拒绝导入；设备编辑保留 ID；JSON 导出再导入不丢字段；三维实体与设备列表一致；通过类型检查、构建、行为测试和浏览器操作验证。

## 使用入口

1. 打开右上角“配置与台账”。“隧道与洞筒”设置名称、入口中心经纬度、绝对高程、方位角、纵坡和洞筒。每个洞筒设置起止桩号、车道宽度、数量与各车道方向。减少洞筒会提示删除关联台账，保存前仅修改草稿。
2. “设备与设施台账”可新增、搜索和编辑记录。从三维设备详情点击“编辑位置与台账”可直接打开对应记录。安装高度按设备安装参考点计算，模型内置原点由渲染器校正；横向偏移沿线路左负右正。区间设施可填写结束桩号。
3. “批量录入与备份”下载适用于当前项目的 CSV 模板。Excel 另存为 CSV UTF-8 后导入，先检查预览。存在重复编号、未知洞筒、非法数值或越界桩号时不能加入草稿。当前支持 CSV / TSV，不直接读取 XLSX。
4. “保存并应用到场景”将草稿写入 IndexedDB 并重建三维。设备 ID 保留，单设备控制设置按项目及设备 ID 单独保存；修改台账位置后可以继续控制同一设备。
5. JSON 导出包含项目、洞筒、车道和台账，带版本号。导入先替换草稿，应用前不影响当前场景。“返回原演示场景”移除已应用项目配置，恢复固定双洞演示，不删除原始模型或标牌图片。

## 当前边界

本批支持 1～2 个物理洞筒，每洞 1～6 条车道，独立车道方向，递增或递减桩号。允许设备位于洞口前后 240 m 引道。地理线路当前为直线，位置、高程和纵坡须由项目资料填写，尚不支持设计曲线、断链和 GIS 线形文件导入。

可配置的结构模型与原精细洞口演示模型分开。当前设备仍使用已有模型与开关控制；灯光亮度、卷帘门开度等按后续设备类型逐项细化。所有控制和读数仍是本地演示，未接入设备协议。浏览器存储不是多用户后台；正式共享与权限控制后续接入业务服务。JSON 备份结构与台账配置，不代表现场设备执行记录。
