# 设备状态面板首版

本版面向领导查看与值班巡检：场景保持主要位置，正常时最多显示 4 个空间标签，优先顺序为选中设备、异常设备、普通监测设备、车辆。标签沿用原有遮挡检查和避让逻辑，完整读数与操作固定在右侧。

## 告警行为

右上角显示当前所有异常设备，来源与详情相同的 `deviceTelemetry`，包括风机故障、摄像机离线、CO 超限和交通演练关联的传感器异常。提示没有关闭按钮、没有超时清除；切换镜头、关闭详情或按 Escape 都不会清除告警。点击告警定位对应设备。恢复设备状态或解除相应演练后，提示自动消失。正常停机不会被当作故障。

本项目当前只有本地模拟数据，未接入真实监测。刷新页面会重置本地演练状态，本版没有新增跨刷新存储或真实告警服务。

## 界面与光效

- 右侧详情分为状态、当前数值、设备信息和原有操作，明确标注模拟来源。
- 保留深蓝色界面；顶部细光线、选中标签的淡蓝轮廓和告警初次出现时三次轻微脉冲，不持续闪烁。
- 原有三维模型描边继续沿用；不改变模型、场景清晰度和原生渲染分辨率。
- 设备告警与右侧面板之间预留空间，空间标签同时避让它们。
- 支持键盘焦点、Escape 关闭详情、减少动态效果偏好；窄屏保留右侧告警和可滚动详情。
- 没有新增图表、虚构健康评分或真实设备控制，保留现有本地演练操作。

## 实现范围

`DeviceAlerts.vue` 只呈现告警并发出定位事件；`DeviceInspector.vue` 呈现详情与原有操作；`SceneOverlayLayer.vue` 保留空间标签投影并避让面板；`CesiumViewport.vue` 组合这些组件，状态从原演练状态派生。

`tsconfig.json` 允许在不生成 JS 的项目中导入 `.ts`，以便新增的 Node 测试直接验证现有设备读数及告警派生函数；构建仍由 Vite 处理。

核心界面及引擎文件的修改前副本保存在 `/tmp/codexaigis-panels-20261028-120235/`。此路径是本机临时回退点，不属于发布包。`before-fan.png` 是修改前详情截图，最终截图与验证记录见同目录。

## 设备切换过渡补充

从设备 A 切换到 B 时，镜头改用约 0.9 秒的缓入缓出飞行，固定右侧容器内的详情按设备 ID 重新播放 0.32 秒轻移淡入。普通洞内设备限制飞行最高点为起止高度，避免默认定位飞行额外向山体上方抬升。连续切换会取消上段镜头运动，以最后一次选择为准；已有详情内部的键盘焦点保留。

“减少动态效果”下镜头直接定位、详情不播放动画。网页对风机 1 → 2 记录到多个连续投影位置，数据见 `selection-motion.json`；同时检查连续切换最终设备与键盘焦点。42 项测试和构建通过。
