# 场地细节与操作流程

2026-10-29，基线 `a9d4a23`。

## 场景

- 原岩壁增加连续起伏，洞门及拱圈附近留出保护区，坡顶与坡脚渐变衔接。保持原山体三角形数量和原有植被、石块实例变换。
- 增加独立的 `portal-finishes.glb`，包含分簇坡脚碎石、路肩、排水沟、格栅、洞门面板接缝与压顶滴水边。
- 两端复用同一模型与坐标约定，新增细节随地下结构开关隐藏，并沿用昼夜照明。
- 附加模型 90,620 字节，每端 27,256 个有效三角形，使用 GPU 实例复用。没有调整渲染分辨率。几何预算不代表已验证长期帧率。
- 这些是演示场地细节，不代表真实工程设计参数。

构建脚本使用现有 glTF Transform CLI SDK：

```bash
npm exec --package=@gltf-transform/cli@4.3.0 -- node --experimental-strip-types scripts/sculpt-portal-cliff.cjs SOURCE.glb OUTPUT.glb
npm exec --package=@gltf-transform/cli@4.3.0 -- node --experimental-strip-types scripts/build-portal-finishes.cjs
```

雕刻脚本必须使用本轮修改前的山体作为输入，源和目标路径不同，避免重复叠加起伏。
