# 隧道画质改进与验收

日期：2026-11-11。本轮先解决高分屏采样和洞内大面积材质的受光；不改变设备台账、位置、控制状态或场景结构。

后续进展见[第二轮光影样板与 GPU 验收](round2.md)。下面保留第一轮记录。

## 计划与实施

1. **高分屏清晰度**：关闭 Cesium 的 `useBrowserRecommendedResolution`，保留 `resolutionScale=1`，按设备物理像素渲染。没有加入动态降分辨率。
2. **墙面与路面**：复用原素材配套的 OpenGL 法线贴图；使用 ARM 的遮蔽、粗糙度通道，增加受光和克制的高光。移除原材质逐像素随机颗粒，接缝使用屏幕导数抗锯齿，重复贴图使用连续采样梯度。
3. **光照层次**：通过 UV 导数重建法线坐标系，使用近似局部灯光方向计算漫反射和高光；沿用原有逐设备照明场调节最终光量。墙脚增加接触暗部，洞外路面使用场景方向光方向。
4. **验证**：检查高分屏、白天、夜间、关灯、洞口、设备控制回归、类型检查和构建。

## 已验证

- 在同一 1280×800 CSS 像素视口、DPR=2 下，修改前画布为 1280×800，修改后为 2560×1600。DPR=1 时保持 1:1。
- 浏览器实际执行了新增 GLSL，洞内白天、夜间与关闭基本/加强照明后均正常显示；未出现 Cesium 渲染错误面板。
- 夜间自动照明仍能照亮内壁；手动全关灯后内壁、路面及其高光随照明场变暗。
- 西洞口路面正常显示；截图不代表洞口所有既有模型问题均已解决。
- `pnpm typecheck`、`pnpm build` 和 `git diff --check` 通过。构建保留原有大包提示。
- 完整测试：98 项，97 项通过。唯一失败为既有 `models/source/portal-access.blend` 归档 SHA-256 不一致；本轮没有修改归档或登记值。
- 设备独立控制、隧道系统与断面相关测试单独运行：20/20 通过。

## 性能与边界

- 本机验收浏览器报告 Apple M5 / ANGLE Metal。新版本 1280×800、DPR=2 下短时 requestAnimationFrame 采样约 6–14 FPS；原材质在相同物理分辨率下的采样约 1 FPS。样本波动明显，且包含页面重载和资源预热影响，不能据此声称性能提升，也不能视为流畅度验收通过。
- DPR=2 相比原 CSS 像素渲染增加到四倍像素量。保留完整分辨率；下一阶段需在实际使用窗口持续巡检，采集稳定的帧耗时后定位瓶颈。
- 局部灯光方向仍按既有规则间距和名义安装高度近似计算，不是每盏可移动灯具的真实点光源，也不产生设备投影或全局光照。已有逐设备亮度数据继续生效。
- 本轮没有新增湿地反射、Bloom、景深或电影调色；尚未达到参考游戏的整体美术效果。后续可在性能基线稳定后，针对一段隧道验证真实接触阴影与灯光空间分布。
- 既有法线源文件逐字节复用：`modelSources/legacy/隧道内墙体贴图_1k.gltf/textures/pebble_embedded_concrete_02_nor_gl_1k.jpg` 与 `modelSources/legacy/clean_asphalt_1k.gltf/textures/clean_asphalt_nor_gl_1k.jpg`。没有引入新的第三方素材来源。
