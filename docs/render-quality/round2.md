# 第二轮：洞内光影样板

日期：2026-11-11。范围为第一个洞筒、“洞内”默认视角前方约 100 米。1900 米演示隧道对应 K0+440～K0+540，两端各用 8 米过渡；暂未推广到全隧道。

## 实施

- 样板内壁、路面和路缘的局部光照读取实际设备世界坐标及独立开关、亮度。位置预览、取消与配置更新都会刷新光源。默认策略关闭时，单独开启的灯具仍然有效；另一洞筒不参与计算。
- 每盏灯影响半径 14 米；按距样板中心的距离最多选取 40 盏有效灯具，限制每像素计算量。默认日间本次实际为 16 盏。密集自定义布灯超过此上限时不会全部参与样板照明。
- 修正双面材质按固定相机轴翻转法线的问题，改为按照片元到相机的方向判断，避免两侧墙面受光不一致。
- 样板墙面降低颜色颗粒对比和法线强度，调整纹理尺度；保留接缝与墙脚暗部。样板以外沿用第一轮材质。
- 新增屏幕空间接触遮蔽，只在相机位于样板附近且墙体可见时启用。遮蔽图为主画布宽高的一半，合成输出仍为原生分辨率；没有下调主场景的分辨率。退出样板或销毁、重建洞筒时关闭、释放对应资源。
- 控制更新时将灯具列表的整理移到模型循环之外，避免每个模型重复构造相同列表。

局部照明采用带距离衰减的点光源和少量近似间接光，不是完整全局光照。接触遮蔽依赖当前画面深度，不是灯具的实时投影；不会计算画面外物体的遮挡。设备模型本身仍沿用原有照明逻辑，新增实际灯位计算针对墙面、路面和路缘。

## 浏览器验证

环境：Ego Chromium，Apple M5 / ANGLE Metal；1280×800 CSS 像素、DPR=2，画布保持 2560×1600。

- 完整重载成功，无材质编译错误或 Cesium 渲染错误面板。
- `basic-125` 位置预览：沿线路 +3 米、横向 +1 米、高度 +0.8 米，光源局部坐标从 `(6.000,-0.250,4.736)` 变为 `(9.000,-1.250,5.579)`；Z 包括线路坡度。其他灯具坐标不变，预览后已恢复原位置。
- `basic-125` 调光至 25%，对应光强从 1 变为 0.25；关闭后有效光源从 16 变为 15，其他光源位置及光强不变。验证后恢复原设备控制记录。
- 白天、夜间自动策略、手动关闭照明均实际渲染。未改变用户原有设备位置和场景配置。
- 首帧问题已修复：Fabric 缓存重用时矩阵需要显式 `mat4` 类型；GLSL 保留字不能作为局部变量名。矩阵重复创建已加入回归测试。

## 性能测量

固定同一相机和车辆位置，临时暂停模拟与浮动信息更新；同页切换样板效果，避免页面重载、资源加载干扰。使用 `EXT_disjoint_timer_query_webgl2` 读取 GPU 时间，每组 9 次绘制，丢弃前 3 次；以下为两次反向顺序采样的中位数。测量后恢复模拟和事件处理。

| 同页模式 | GPU 中位耗时，正序 | GPU 中位耗时，反序 |
| --- | ---: | ---: |
| 关闭样板效果 | 27.52 ms | 34.33 ms |
| 实际灯位与样板材质 | 36.18 ms | 38.50 ms |
| 再开启最终接触遮蔽 | 40.14 ms | 42.39 ms |

样板照明和材质增加约 4～9 ms，最终接触遮蔽约增加 4 ms。整套样板效果相对关闭状态约增加 8～13 ms；此轮改善画质，**没有使整个场景更快，也不代表达到 60 FPS**。正反序间存在负载漂移，不能把短时样本当作持续漫游的帧率承诺。

此前全分辨率 HBAO 试验额外消耗约 16～22 ms，已撤下。最终只缩小柔和的遮蔽图，保留原生主场景颜色、几何边缘和输出分辨率。

预热后的环境/照明控制更新，改动前约 23～28 ms（中位 27.1 ms），整理灯具列表一次后约 17～22 ms（中位 18.4 ms）。这是控制更新耗时改善，不是连续绘制帧率改善；首个冷启动样本未计入。

场景仍有大量模型和独立构件命令，尚未实施全局合批或场景剔除重构。本轮没有通过删除设备、隐藏必要模型或降低主画面分辨率获取性能。
