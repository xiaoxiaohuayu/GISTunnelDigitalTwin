# 隧道场景调整验收

## 使用入口

- 直接点击三维场景中的入口标牌即可打开编辑器，也可从右上角“系统控制”底部进入。可修改中英文名称、长度、黄色提示区、文字配图或整张图片，保存后两端同步更新。长度留空使用测绘长度。
- 入口标牌采用路侧单立柱、双横臂悬挂结构；默认牌面为隧道图标、中英文名称、长度和黄色“请开灯行驶”提示。
- 配置和图片保存在当前浏览器、当前站点的 IndexedDB 中；更换浏览器或站点地址不会同步。
- 右上角“事件演练”打开抽屉。关闭抽屉不解除演练，记录保留到本次页面结束。
- 附近车辆及检测设备显示带引线的模拟信息卡片。点击三维设备、设备列表或信息卡片会统一选中并定位；蓝色表示选中，红色或黄色表示告警。

## 模型维护

摄像头保留原有几何和法线，默认机身使用非金属浅灰材质，镜头区域使用深色材质。重新转换资源时，`scripts/convert-site-assets.py` 会调用 `scripts/repair-camera-materials.py` 保持这些默认材质。原始模型未改动。

车辆身份和读数为本地演示数据。浮层在 150 米内显示，最多 20 个，优先选中、告警及近处目标，并避让抽屉与导航。初始化进度按阶段和任务计算，不表示下载字节百分比。
