## 3. 场景与 UI 的还原要求

### 3.1 入口参考

![入口与主界面参考](frames/second-001.jpg)

- 中央标题为“隧道数字孪生一体化平台”，青色发光、折线形标题底板。
- 左上天气图标一排，右上“首页”，两侧有收起样式箭头。
- 左侧设备、右侧事件，六边形图标和青色文字，选中后黄色。
- 底部“隧道入口”“行车”“漫游”“数据看板”，行车和漫游间有橙色小图标。
- 道路和双洞所在山体、管理建筑、白色挡墙的布局必须保持。
- 水印“可视化宇宙 bilibili”、底部讲解字幕、录制提示属于视频叠层，不还原进产品。

天气按钮的真实作用、收起按钮操作和橙色小图标含义没有得到完整演示，按 B/U 登记。不要默认补成气象接口、场景编辑器或退出按钮。

### 3.2 洞内和标注

洞内为道路隧道，具有拱形断面、分段灯光、路面标线、顶置设备和车辆。暗部应保留体积层次。不能只用蓝色自发光线框表示隧道。

事件卡采用红色半透明边框、红色标题和细小白字，通过引线指向目标。卡片正文与时间不完全可辨；后续可用明确标为演示的内容填充，但应记录其并非原文复刻。

侧向展示能看到洞内车辆和照明，周围近黑。视频没有证明存在一个独立“剖切”开关，只能确认出现了这种展示视角。

## 7. 漫游与检测设施

约 63 秒返回场景后“漫游”呈黄色，镜头向洞口移动，并查看道路检测区域和龙门架。

可见的检测表达包括路面白色多边形轮廓、浮动标签与引线、门架上的半透明粉红锥/棱台覆盖体。覆盖体需要有空间体积和透明叠加关系，不能简单画成屏幕上的粉红三角形。

车辆持续运动，画面中可见货车及多色轿车。没有充分证据判断由自动交通仿真还是预设轨迹驱动。

## 9. 解说提及但未完整演示

内嵌字幕提到 GIS/BIM/IoT，模型放置、传感器接入、交互配置、客户端编辑器、导出可执行文件和接口二次开发。还提到结构健康监测、车流量态势感知、照明通风联动、应急处置调度等后续应用。

这些信息为 C 级。不能据此认定视频演示系统已经拥有完整编辑器、生产级物联网平台或应急调度闭环。也不能根据营销表达断言零代码、无性能限制或任意硬件流畅运行。
