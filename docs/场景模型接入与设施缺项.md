# 场景模型接入与设施缺项

本轮更新在 **GIS 地图** 中。独立的 Three.js 精细样板仍是此前的局部样板，未将两套场景全部合并。参考视频切片 `second-001`、`005`、`007`、`009`、`013`、`016`、`056`、`073` 至 `089`。设备尺寸、间距、数量均为演示布局，不是视频精确测量或真实工程资产。

## 已接入

| 资源 | 处理与使用 |
| --- | --- |
| 树木.zip | 解包 Finish tree.blend 的枝叶粒子实例、恢复树皮/叶片贴图；近处使用抽稀枝叶网格，远处使用该完整树木渲染出的三面交叉贴片，叶片采用透明裁切。替换原球状树冠。 |
| 石头.blend | 使用 a/b/c 三种高细节石头的网格，烘焙灰岩表面材质。原文件没有石头图像贴图。替换原二十面体石头；整面岩壁使用独立可重复纹理。 |
| 路灯.fbx | 选择单臂曲杆版本，归一为 8 m，降低多余面数；双洞道路两侧按 24 m 演示间距布置。 |
| 变电所.blend | 保留打包的 PBR 贴图，缩至适合浏览器的分辨率，替换中央简易房。增加“变电所”定位按钮。 |
| 护栏.fbx | 原文件为分散的端件与支撑零件，未直接把零件集合重复铺路。自行制作连续波形钢板、立柱、螺栓与反光片。 |
| 低模车辆.blend | 从模型包选取两款完整轿车与一款 SUV。原文件缺少 color_1024x1024.jpg，重建车漆、玻璃、轮胎、轮毂材质。24 辆演示车分双洞、双车道循环行驶，同车道速度一致，保持间距；进入后台后限制单次时间步长。 |
| 摄像机.blend | 转换枪式摄像机，在洞内演示布置；与柜体、风机均按近距离显示控制开销。 |
| 消防栓.blend | 从原文件多组箱体中筛选一组柜体并降低面数，替换原方块消防占位。具体消防型号与视频是否一致仍需比对。 |
| 风机.obj | 使用原轴流风机网格作为前端组件，补建中空长筒和吊架，形成洞顶成对射流风机。 |
| 高模 Audi | 未用于车流，以避免把高面数车辆重复加载到隧道中。 |

原始 `blendFile/originals/legacy` 和 `modelSources/legacy` 文件保持不变。模型转换统一为米制、沿 X 前进、Z 向上；Cesium GLB 导入显式指定 Y-up、X-forward。车辆轮胎目前不单独旋转，车流按预设线路运动，不包含交通算法、检测或业务统计。

## 与视频相比仍缺什么

后续已补充洞内车道指示器、悬挂情报板、SOS 电话、连续路沿、桥架及真实加宽的紧急停车带，见 [洞内设施与停车带](洞内设施与停车带.md)。下表保留上一轮比对记录，以该补充文档为当前状态。

| 设施 | 当前差距 | 建议资源 |
| --- | --- | --- |
| 入口限速与禁令牌 | 视频约 15 秒有圆形 60 限速及禁令组合，当前没有对应实体标牌。 | 可自行建模，用户无需找复杂模型。需确认其他禁令牌含义。 |
| 入口信号灯、车道指示器 | 视频约 9、12 秒有信号灯、绿箭头/红叉；尚未建成对应实物。 | 可自行做灯箱、支架、发光面。 |
| 情报板与门架 | 目前是简化门架和红字板，缺桁架、检修平台和细部。 | 可自行补结构；若有与视频接近的门架模型可替换。 |
| 警视一体机、紧急电话 | 还没有可确认型号的对应实物。 | 建议提供模型或清晰近景，避免把摄像机误当成这两类设备。 |
| 控制柜与黑黄底座 | 变电所已接入，但不等于视频约 16 秒、巡看时出现的道路侧智能控制柜。 | 建议提供道路控制柜；底座和黄黑条纹可自行制作。 |
| 道路检测门架、检测覆盖体 | 尚无视频 73–89 秒的独立检测门架、路面检测轮廓、标签和粉色空间覆盖体。 | 门架有模型更好；覆盖体与轮廓可直接编程制作。 |
| 洞内消防与疏散细节 | 现有柜体、出口牌和通道，仍缺更准确的消防柜样式、灭火器、管线、门框细节。 | 建议提供隧道专用消防组合柜及防火门，或清晰设备近景。 |
| 灯槽、电缆桥架、衬砌 | 灯具、衬砌仍较简化，缺真实分段接缝、瓷砖/涂层、桥架支撑、排水沟与反光诱导设施。 | 可以自行制作，若有工程贴图可提高匹配度。 |
| 车型与事件道具 | 已有运行轿车/SUV，尚未覆盖视频中的货车、作业车、施工围挡、人员、抛洒物。 | 优先找低模货车、作业人员和施工车辆；普通围挡可自行建模。 |
| 山体外观 | 新树石已替换，但地形轮廓、树种分布、岩壁材质和视频仍不完全一致。 | 若有带基础色/法线/粗糙度的岩壁和草地贴图，可继续替换。 |

设备数据统计、真实监控流和检测算法不在本轮实现范围内。

## 重建

在项目根目录使用 Blender 4.5：

```sh
/Applications/Blender.app/Contents/MacOS/Blender -b --python scripts/convert-site-assets.py -- props
/Applications/Blender.app/Contents/MacOS/Blender -b --python scripts/convert-site-assets.py -- trees
/Applications/Blender.app/Contents/MacOS/Blender -b --python scripts/build-jet-fan.py
/Applications/Blender.app/Contents/MacOS/Blender -b --python scripts/build-portal-site.py
pnpm build
```

树木转换前将 `modelSources/legacy/树木.zip` 解压至 `blendFile/originals/trees/`。可编辑的入口总场景为 `blendFile/scenes/portal-site.blend`，转换后的中间模型为 `blendFile/prepared/`，浏览器资源为 `src/assets/modelAssets/portal/portal-*.glb` 与 `src/assets/modelAssets/equipment/`。只把使用中的资源导出到浏览器目录，避免发布高精度中间模型。
