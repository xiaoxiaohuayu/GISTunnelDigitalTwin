# 洞内设施与紧急停车带

本轮针对 GIS 地图，按用户新增参考图完善双车道隧道。原视频与新增参考图共同用于外观对照，设备数量、间距、尺寸均为演示设定。

## 已完成

- 每条隧道按行驶方向安装成组的绿箭头车道指示器，包含灯箱、发光箭头、吊杆和顶部固定件。
- 增加悬挂式情报板及支架，显示“保持车距 注意安全”。牌面为实体模型，未实现远程发布或业务控制。
- 两侧连续路沿、检修步道、排水沟、黄黑斜纹警示面；联络通道位置保留通行口。
- 增加墙面分层、瓷砖分格和衬砌环向接缝，混凝土与沥青表面细节、分段灯具及连续电缆桥架。
- 增加实体安全出口灯箱、SOS 紧急电话，保留已接入的摄像机、消防柜和成对风机。
- 双洞分别设置一处紧急停车带，墙体、顶拱、路面、路沿和桥架随断面加宽，包含引导虚线、地面文字、停车标志及挡车器。
- 增加“紧急停车带”视角，已有行车漫游可经过这些设施。

## 演示布局

停车带位于上行 32%、下行 68% 线路长度处，局部外侧加宽 3 m，中间平直段 60 m，两端各 12 m 渐变段。两条主行车道保持连续，演示车流沿主车道行驶，不包含自动驶入停车带的交通逻辑。

车道指示器按 180 m 演示间距、情报板按 300 m 演示间距放置，分别朝向东西两种行车方向。最近情报板底部相对路面约 5.1 m，车道灯底部约 5.2 m；这些仅为模型净空检查，不代表工程认证。

## 实现文件

- `src/engines/tunnelLayout.ts`：停车带位置和渐变断面。
- `src/engines/tunnelInterior.ts`：可变断面内壁、路面及连续警示路沿；按米设置材质坐标，并关闭顶点压缩，避免纹理坐标被压缩为 0–1 范围造成条带。
- `src/engines/tunnelDetails.ts`：步道、排水沟、灯具和桥架。
- `src/engines/tunnelEquipment.ts`：按断面、行驶方向定位设备。
- `scripts/build-interior-fixtures.py`：重建实体灯箱、情报板、电话和停车带标识。

重建灯箱和标牌：

```sh
/Applications/Blender.app/Contents/MacOS/Blender -b --python scripts/build-interior-fixtures.py
pnpm build
```
