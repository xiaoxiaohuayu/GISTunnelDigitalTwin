# 视频功能细化记录

本轮以 `video-analysis/视频逐段分析.md` 及原始逐秒帧为依据，扩展现有 GIS 场景。视频证据与本轮新增的演示逻辑分开登记；没有接入真实告警识别、监测协议或视频流。

| 视频片段 | 本轮实现 | 本地演示边界 |
| --- | --- | --- |
| 18–24 秒，违停、拥堵、落石、抛洒物 | 事件菜单、定位、路面道具及车辆状态，事发方向可切换 | 手动触发；没有自动检测和清障调度 |
| 25–27 秒，风机故障高亮 | 保留风机故障动效，详情可控制同组风机、切换同类设备 | 同组控制，不伪装成单台 PLC 命令 |
| 28–35 秒，施工 | 施工锥桶、围挡、作业车与人员、空间事件标注 | 通用示意几何，不是工程施工模型 |
| 36–39 秒，应急车道、压线 | 停车带占用、压线车辆，方向定位及提示 | 未实现识别与取证 |
| 40–49 秒，火灾、烟雾、行人 | 火焰、烟雾、行人实体与事件标注 | 消防与通风联动仅用于页面演练 |
| 50–54 秒，车辆 | 车辆实例展示，继续使用地下结构与墙体开关检查洞内 | 当前已有车辆资产，不宣称复刻视频全部车型 |
| 57–62 秒，监控点位 | 摄像机可定位、逐台切换并预览三维模拟视角 | 没有真实视频源，不做伪造的监控矩阵 |
| 63–89 秒，漫游与检测设施 | 双向巡检、30/60/90 km/h、暂停继续、位置拖动、路面检测轮廓及摄像机棱台覆盖体 | 覆盖体表示范围示意，不是厂家标定视场 |
| 90–105 秒，数据看板 | 保持既有用户要求，未新增统计图表；仅记录本页实际触发的演练事件 | 演练记录最多保留最近 8 条，刷新后清空 |

## 联动与恢复

- 严重占道事件使事发洞入口禁行，另一洞保留原有信号和情报板内容。
- 违停只阻挡事发车道，拥堵降低事发洞车速，应急停车带占用保留主车道。
- 火灾、烟雾等联动按本地状态驱动。解除事件关闭对应道具与粒子，并恢复本地交通状态。
- 各设备详情、三维亮面和交通显示共用信号与情报板策略，避免面板显示与模型相互矛盾。
- 巡检暂停后保留当前位置；切换方向从对应引道开始，拖动线路位置后立即更新镜头。
- 遮雨棚保持上一轮已对齐的洞口尺寸，本轮未修改其几何。

## 验证

9 项 Node 测试覆盖原有照明和双面指示、全部交通演示的双洞隔离及解除恢复、拥堵速度、洞口与停车带事件位置、违停车道排队和事件移动后的解除。`pnpm build` 执行 Vue/TypeScript 检查和生产构建。

第一轮 ego-browser 实际操作通过：事件切换、施工场景实体、检测覆盖体、同类摄像机切换、三维监控视角、设备详情中的风机组开关，以及下行洞 30 km/h 巡检与位置拖动。发现广播提示遮挡监控退出按钮，已调整提示位置并去除提示的指针拦截；事件定位镜头也已后退，避免施工围挡贴近镜头。

2026-10-23 最终复核：经用户授权重新创建 ego-browser 检查工作区后，以下项目完成实际操作验证。

- 广播开启时能够退出三维监控预览，提示不再遮挡按钮。
- 火灾定位镜头可见车辆前部火焰、烟雾、空间事件标注与禁行指示；解除演练后广播状态恢复。
- 下行洞 30 km/h 巡检、位置拖动、暂停后继续正常，恢复行驶后位置按下行方向递减。
- 430 × 900 视口无横向溢出，事件面板与底部导航不重叠。监控退出按钮命中检查通过，模拟触屏操作成功退出预览。
- 本次捕获的页面脚本异常、未处理 Promise 异常及 Cesium 渲染错误均为 0。
- 9 项测试与生产构建此前已通过，本次未修改场景源代码。
